# ⚡ Gidelmar Jr. | Portfólio Profissional

> Portfólio de desenvolvimento Full Stack focado em back-ends robustos, interfaces claras e segurança da informação.
> 
---

## 🚀 Sobre o Projeto
O **G.JR Portfólio** é a aplicação web de apresentação pessoal e profissional desenvolvida para destacar competências em engenharia de software, arquitetura de sistemas e segurança. O projeto conta com um design moderno em dark mode com detalhes em vermelho/laranja de alto impacto visual, suporte a múltiplos idiomas (PT/EN), alternância de tema e seções imersivas para exibição de projetos.

- **Deploy Online:** [Acessar Projeto na Vercel](https://gidelmarjr.vercel.app/)

---

## ✨ Funcionalidades
- **Design Responsivo & Imersivo:** Layout sofisticado em dark mode com tipografia marcante e ticker inferior contínuo de tecnologias.
- **Internacionalização (i18n):** Alternância fluida entre Português (PT) e Inglês (EN).
- **Seções Estruturadas:** 
  - *Hero* com proposta de valor e chamadas para ação (*Iniciar um projeto* / *Ver projetos*).
  - Vitrine de projetos e experiências em desenvolvimento Full Stack, Back-end e Segurança.

---

## 🛠️ Tecnologias Utilizadas
- **React** (com Framework moderno)
- **CSS Modules / Tailwind CSS** (estilização componentizada)
- **Vercel** (Hospedagem e CI/CD)
